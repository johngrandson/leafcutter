# Research

Esta pasta contém material de estudo e comparação. É **não normativa**.

Pesquisa pode:

- explicar conceitos externos;
- avaliar fit com Leafcutter;
- sugerir tradeoffs;
- motivar uma proposta.

Pesquisa não pode, sozinha:

- fechar boundary;
- adicionar dependency;
- criar schema/processo;
- alterar ADR aceito;
- declarar capacidade materializada.

Para estado atual, use `architecture/estado-atual-e-visao-futura.md`. Para decisão, use ADR.
