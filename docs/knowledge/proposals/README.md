# Propostas de conhecimento

Este diretório contém candidatos persistidos e não ativos. Eles não alteram o
roteamento, não participam da consulta normal e não estabelecem authority.

## Contrato canônico

`../README.md`, na seção `Propostas persistidas`, define o formato, os targets
permitidos e o ciclo de vida completo. Este arquivo registra apenas o
ownership do diretório para não manter uma segunda cópia do contrato.

Cada candidato é um arquivo Markdown diretamente neste diretório. Agentes
podem criá-lo somente após pedido explícito de captura. Propostas permanecem
fora da consulta e não estabelecem authority até a promoção aprovada.
