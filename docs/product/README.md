# Produto

A visão de produto inclui capacidades já disponíveis como foundation e capacidades completas ainda planejadas.

- `product-capabilities.md`: matriz entre disponibilidade atual e roadmap.

A presença de uma capacidade na visão de produto não significa que existe endpoint, UI ou workflow completo hoje. Use `architecture/estado-atual-e-visao-futura.md` para o estado técnico.
