# ADR-0013 — Idioma e documentação

- Status: Accepted
- Estado de implementação: MATERIALIZADO

## Decisão

Código, nomes, docs in-code, tests e contracts técnicos são em inglês. Documentação arquitetural fora do código permanece em pt-BR.

APIs públicas relevantes usam `@moduledoc`, `@doc`, `@typedoc`, `@spec` e erros nomeados.

## Consequências

Docs de schema seguem sections canônicas. Typespecs genéricos são evitados quando a forma é conhecida.
